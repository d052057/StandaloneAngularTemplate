Standalone Angular Template

.NET 9 API + Angular 22 (standalone components) + Bootstrap 5 — install once, scaffold new projects from Visual Studio 2022

Prerequisites

  • Visual Studio 2022 with the ASP.NET and web development workload (includes the Node.js development tools)
  • .NET 9 SDK
  • Node.js (LTS) and npm

Check your SDK with dotnet --version and Node with node --version from a terminal.

1 Install the template

Download or clone this repository, then open a PowerShell/cmd prompt in the folder that contains the template source (the folder with StandaloneAngularTemplate.sln and .template.config):

dotnet new install .

This registers the template with the dotnet new engine so it's available every time you scaffold a new project, from any folder.

2 Create a new project from the template

From any folder where you want the new project created (e.g. source/repos):

dotnet new standalone-angular -o MyNewProject

Replace MyNewProject with whatever you want to call your app. This creates a new folder with the server + client projects, solution file, and a fresh sourceName already substituted throughout.

3 Open and run in Visual Studio 2022

Open the generated .sln file in Visual Studio 2022, make sure the server project is set as the startup project, and press F5. Visual Studio will restore npm packages, launch the Angular dev server, and open your browser automatically.

Uninstalling the template

If you no longer want the template registered:

dotnet new uninstall StandaloneAngularTemplate.template

Troubleshooting common

npm start fails right after creating a new project — node_modules sometimes ends up incomplete. Fix with a clean reinstall from the client project's folder:

rmdir /s /q node_modules
npm install
ng build

Port or certificate errors on first run — Visual Studio should prompt to trust the local HTTPS dev certificate the first time you run the project. Accept that prompt; if it doesn't appear, run dotnet dev-certs https --trust from a terminal.
